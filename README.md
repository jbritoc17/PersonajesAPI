# 👾 Personajes API - Proyecto de consumo de API

Aplicación web sencilla que muestra información de personajes consumida desde una API externa, desarrollada para practicar **fetch** y manipulación del **DOM** en JavaScript.

## 🚀 Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript (ES6+)

## 📋 Características
- Consumo de datos desde API pública
- Renderizado dinámico de tarjetas de personajes
- Uso de funciones asincrónicas (`fetch`)
- Manejo básico de errores de conexión
- Diseño adaptativo básico

## 🎯 Qué aprendí
- Cómo consumir APIs REST usando `fetch`
- Cómo recorrer y manipular arrays de objetos en JavaScript
- Creación dinámica de elementos HTML desde JS
- Mejorar habilidades de estructuración de código
